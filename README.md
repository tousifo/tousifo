### About

I am a Lecturer in Computer Science & Engineering working at the intersection of machine learning and physical systems. My work spans quantum machine learning for medical imaging, humanoid robotics, and AI-assisted education, with an emphasis on turning research ideas into systems that run in the real world.

### Research Interests

| Area | Focus |
| :--- | :--- |
| **Quantum Machine Learning** | Hybrid quantum–classical models, multiple-instance learning for medical imaging |
| **Machine Learning & Computer Vision** | Deep learning, applied ML, MLOps and deployment |
| **Robotics & Embedded Systems** | Humanoid platforms, autonomous navigation, human–robot interaction |
| **AI in Education** | Retrieval-augmented generation and LLM-based academic assistants |
